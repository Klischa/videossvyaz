# Звонок через «комнату» Firebase (постоянный ключ)

Режим **«Позвонить (комната)»** позволяет звонить одному человеку в один тап без
обмена ссылками: оба вводят одинаковый **код комнаты** один раз, дальше звонок
устанавливается автоматически. Код комнаты — это и есть ваш «постоянный ключ».

Приложение работает с Firebase **через REST API** — без `google-services.json`,
без Firebase SDK. Нужна только база Realtime Database.

---

## 1. Создать проект Firebase
1. https://console.firebase.google.com → **Add project** (имя любое).
2. В меню слева → **Build → Realtime Database → Create Database**.
3. Выберите регион, в правилах на старте можно оставить **test mode** (30 дней) —
   потом поправим.

## 2. Взять URL базы
Вверху вкладки Realtime Database виден URL вида:
```
https://ваш-проект-default-rtdb.europe-west1.firebasedatabase.app/
```
Скопируйте его.

## 3. Правила (Rules) — открыть чтение/запись
В Realtime Database → вкладка **Rules** поставьте (для личного инструмента):
```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}
```
> Это открывает запись/чтение только под узлом `/rooms`. Узнав код комнаты,
> теоретически кто-то может вмешаться — поэтому делайте код комнаты длинным
> и неочевидным (например `alex-masha-2026`). Для полной приватности нужен
> Firebase Auth + правила по пользователю (сложнее).

Опубликуйте правила (Publish).

## 4. Настроить оба телефона
В приложении: **Настройки** → впишите:
- **Firebase URL** — скопированный URL базы (без завершающего `/`).
- **Код комнаты** — **одинаковый** на обоих телефонах (ваш постоянный ключ).

Сохранить.

## 5. Звонить
Главный экран → **«Позвонить (комната)»**.
- Кто нажал первым и в комнате ещё нет offer → становится инициатором.
- Кто нажал вторым (видит готовый offer) → автоматически отвечает.
- Соединение устанавливается само. ICE/NAT по-прежнему прикрывается TURN из настроек.

---

## Замечания
- Firebase не хранит ключи постоянно — каждое соединение создаёт новые offer/answer
  (так устроен WebRTC), но **пользователь** обменивается только кодом комнаты один раз.
- Лимиты бесплатного тарифа Firebase: достаточно для личных звонков.
- Если «ответ не получен (таймаут)» — второй абонент не нажал «Позвонить» в течение
  ~90 сек, или не совпадает код комнаты / URL базы.
