# Свой сигнальный сервер на Windows 7 (вместо Firebase)

Режим **«Позвонить (комната)»** может работать **без облачного Firebase** —
через маленький сервер в вашей домашней сети на компьютере с **Windows 7**.

Что вы получаете:
- звонок в один тап по постоянному коду комнаты — как с Firebase;
- **никакой зависимости от Google-облака**, данные хранятся у вас дома;
- сервер — один файл `server/signaling_server.py` на **чистом Python без
  библиотек** (ничего ставить через pip не нужно).

---

## 0. Важно: что будет на Win7, а что — нет

В видеозвонке две «серверные» функции:

| Функция | Где работает | Комментарий |
|---------|--------------|-------------|
| **Сигналинг** («комнаты»: обмен offer/answer) | ✅ **на Windows 7** (этот сервер) | Достаточно для звонка в один тап |
| **TURN** (релей видео при «тяжёлом» NAT) | ❌ **не ставится на Win7** | coturn — только Linux; см. варианты ниже |

Практика:
- **Оба телефона в одном Wi-Fi** (дома) → TURN обычно **не нужен**, хватит
  этого сервера + встроенного STUN.
- **Разные сети / мобильный интернет** → скорее всего нужен TURN. Варианты:
  1. TURN на бесплатном VPS по инструкции [COTURN.md](COTURN.md), а сигналинг —
     на домашней Win7 (так тоже работает: в настройках приложения TURN и
     сервер комнат задаются независимо);
  2. Объединить телефоны и ПК в одну VPN-сеть (ZeroTier, Tailscale, Radmin VPN) —
     тогда TURN опять не нужен, а сервер доступен из любой точки мира;
  3. Продолжать пользоваться Firebase для комнат ([FIREBASE.md](FIREBASE.md)) —
     он тоже остаётся поддерживаемым.

## 1. Требования

- Windows 7 **SP1** (x86 или x64), включённая.
- **Python 3.8.10** — последняя версия Python для Windows 7.
  Скачать: https://www.python.org/downloads/release/python-3810/
  - для 64-битной Win7: `Windows installer (64-bit)`;
  - для 32-битной: `Windows installer (32-bit)`.
  - При установке поставьте галочку **«Add Python 3.8 to PATH»**.
- Телефоны и компьютер — **в одной сети** (один Wi-Fi роутер), либо в общей VPN.
- На телефоны установлена **свежая версия приложения** из этого репозитория
  (с поддержкой своего сервера — поле «Сигнальный сервер» в настройках).

> Ничего устанавливать через `pip` не нужно: сервер использует только
> стандартную библиотеку Python. Это же значит, что он запустится даже на
> Python 2.7 / 3.4+, если вдруг на машине стоит старый Python.

---

## 2. Установка сервера (5 минут)

### Вариант 1 — автоматически (рекомендуется) ✅
1. Скопируйте папку `server` из этого репозитория на компьютер с Win7
   (например, `C:\p2pcall-server\`).
2. Правой кнопкой по **`setup-win7.bat`** → **«Запуск от имени администратора»**
   (или просто двойной клик — права запросятся сами).
3. Скрипт всё сделает сам: проверит Python (если нет — скачает и тихо
   установит 3.8.10), откроет порт в брандмауэре, добавит сервер
   в автозапуск и запустит его:
   ```
   [2026-09-08 21:00:00] P2PCall signaling v1.0 запущен!
   [2026-09-08 21:00:00] В настройках телефонов укажите сервер: http://192.168.1.5:8080
   ```
   Запомните адрес вида `http://192.168.x.x:8080` — его вписываем в телефоны.
   Разделы 3 и 5 ниже при этом выполнять **не нужно**.

### Вариант 2 — вручную
1. Скопируйте папку `server` на компьютер с Win7.
2. Установите Python 3.8.10 с https://www.python.org/downloads/release/python-3810/
   (галочка «Add Python to PATH»).
3. Дважды кликните **`start-server.bat`**.
4. Проверка на самом компьютере: откройте в браузере
   `http://127.0.0.1:8080/health` — должен ответить `{"status": "ok", ...}`.
5. Проверка протокола целиком (необязательно, но полезно):
   ```
   python test_room.py http://127.0.0.1:8080 моя-комната
   ```
   В конце должно быть «все проверки пройдены».

Окно с сервером **не закрывайте**, пока нужны звонки (сворачивать можно).

## 3. Разрешить доступ в брандмауэре Windows

Иначе телефоны не достучатся до сервера. Один раз, от имени администратора:

```bat
netsh advfirewall firewall add rule name="P2PCall signaling" dir=in action=allow protocol=TCP localport=8080
```

Либо вручную: *Панель управления → Брандмауэр → Дополнительные параметры →
Правила для входящих подключений → Создать правило → Порт → TCP 8080 →
Разрешить подключение*.

Проверка с телефона: откройте в мобильном браузере
`http://192.168.1.5:8080/health` (ваш IP) — должен открыться JSON-ответ.
Не открылся — смотрите раздел «Не работает» ниже.

---

## 4. Настройка телефонов

На **обоих** телефонах: приложение → **Настройки**:

- **Сигнальный сервер:** `http://192.168.1.5:8080` (адрес из окна сервера,
  без завершающего `/`);
- **Код комнаты:** одинаковый на обоих, например `alex-masha-2026`.

Сохранить. Дальше: главный экран → **«Позвонить (комната)»** на обоих
телефонах — соединение установится само.

> Старый вариант с Firebase продолжает работать: просто впишите вместо
> `http://…` адрес базы `https://…firebasedatabase.app` (см. [FIREBASE.md](FIREBASE.md)).

## 5. Чтобы сервер был всегда под рукой

### Вариант А — автозапуск при включении компьютера
1. Нажмите `Win+R`, введите `shell:startup`, Enter.
2. Создайте там ярлык на `start-server.bat`.
3. В свойствах ярлыка можно поставить «Запускать: свёрнутым в значок».

### Вариант Б — работа без Python (один .exe файл)
На машине с Python 3.8 запустите **`build-exe.bat`** — он соберёт
`dist\p2pcall-signaling.exe`. Этот один файл можно скопировать на любую
Win7 и запускать двойным кликом, Python там уже не нужен.

### Стабильный IP компьютера (рекомендуется)
IP вида 192.168.1.5 роутер может менять. Чтобы не переписывать настройки
в телефонах, задайте компьютеру статический IP:
*Панель управления → Сеть → Подключение → Свойства → TCP/IPv4* —
или привяжите IP к MAC-адресу в настройках роутера (DHCP reservation).

## 6. Файлы и параметры

| Файл | Назначение |
|------|------------|
| `signaling_server.py` | сам сервер |
| `setup-win7.bat` | **автоустановка**: Python + фаервол + автозапуск + старт (можно с портом: `setup-win7.bat 8081`) |
| `start-server.bat` | просто запуск двойным кликом (можно с портом: `start-server.bat 8081`) |
| `test_room.py` | самопроверка сервера |
| `build-exe.bat` | сборка одиночного .exe через PyInstaller |
| `rooms.json` | хранящиеся комнаты (создаётся сам, можно удалять) |
| `server.log` | журнал (создаётся сам) |

Параметры командной строки:

```
python signaling_server.py --port 8080 --ttl 1800 --data rooms.json --log server.log
```

- `--port` — порт (если 8080 занят, возьмите 8081 и укажите его в телефонах);
- `--ttl` — через сколько секунд бездействия комната стирается (по умолчанию 1800).

Комнаты также стираются автоматически в начале каждого нового звонка —
«мусор» не копится.

## 7. Безопасность

- Сервер говорит по обычному **HTTP без шифрования** — это нормально
  **внутри домашней сети / VPN**, но **не выставляйте порт 8080 в интернет**
  напрямую (через «проброс портов» роутера): SDP в комнатах увидят посторонние.
- Нужен доступ из интернета без VPN — используйте Firebase ([FIREBASE.md](FIREBASE.md),
  там HTTPS) или поднимите HTTPS-реверс-прокси (stunnel/nginx) — это уже за
  рамками Win7-инструкции.
- Делайте код комнаты длинным и неочевидным (`alex-masha-2026`, а не `1`) —
  это единственный «пароль» комнаты.

## 8. Не работает? (диагностика)

1. **Телефон не открывает `http://IP:8080/health`:**
   - компьютер и телефон точно в одном Wi-Fi? (гостевые сети часто изолированы);
   - брандмауэр Win7 разрешает порт 8080? (раздел 3);
   - IP не сменился? Посмотрите новый адрес в окне сервера или командой
     `ipconfig` (строка «IPv4-адрес»);
   - сторонний антивирус с фаерволом (Kaspersky, ESET…) — добавьте исключение.
2. **«Ответ не получен (таймаут)» в приложении:**
   - второй абонент не нажал «Позвонить (комната)»;
   - не совпадает код комнаты или адрес сервера на двух телефонах
     (проверьте опечатки, лишний пробел/`/`);
   - сервер показывает записи «записан offer» в логе? Если нет — телефон
     вообще не доходит до сервера (см. пункт 1).
3. **`start-server.bat` пишет «Python не найден»:**
   - переустановите Python 3.8.10 с галочкой «Add to PATH»;
   - либо соберите .exe на другом ПК (раздел 5, вариант Б).
4. **«НЕ УДАЛОСЬ ЗАНЯТЬ порт»:** порт занят другой программой —
   запустите `start-server.bat 8081` и впишите `:8081` в телефоны.
5. **Звонок соединяется, но нет видео («ICE failed»):**
   это уже не сигналинг, а NAT — нужен TURN или общая VPN (см. раздел 0).
   Проверьте, что оба телефона в одном Wi-Fi, для начала.

Если ничего не помогло — приложите к вопросу файл `server.log`
и текст ошибки из приложения.
